# Китайский

Сайт для изучения 28 слов первого урока: карточки, тренажёр порядка черт
(пишешь пальцем или мышкой), тест, список слов с озвучкой, прописи в PDF
и общая таблица прогресса друзей.

Файлы:
- `index.html` — весь сайт
- `firebase-config.js` — настройки базы (заполнить)
- `firestore.rules` — правила доступа к базе
- `propisi.pdf` — прописи для печати

Без Firebase сайт тоже работает, но прогресс хранится только в браузере
и вкладка «Друзья» не работает.

## 1. Создай проект Firebase (бесплатно)
1. Зайди на https://console.firebase.google.com и нажми «Создать проект».
2. Название любое, Google Analytics можно выключить.

## 2. Включи вход через Google
1. В меню слева: **Build → Authentication → Get started**.
2. Вкладка **Sign-in method → Google → Enable**, укажи свою почту, **Save**.

## 3. Создай базу Firestore
1. **Build → Firestore Database → Create database**.
2. Регион любой (например `eur3`), режим **production**.
3. Открой вкладку **Rules**, замени всё на содержимое файла `firestore.rules`
   и нажми **Publish**.

## 4. Скопируй настройки в сайт
1. Шестерёнка → **Project settings** → внизу «Your apps» → значок `</>` (Web).
2. Название любое, хостинг Firebase не отмечай → **Register app**.
3. Из показанного `firebaseConfig` перенеси `apiKey`, `authDomain`,
   `projectId`, `appId` в файл `firebase-config.js`.
   Эти ключи не секретные, их можно выкладывать: защищают данные правила
   из шага 3.

## 5. Выложи сайт
Любой статический хостинг подойдёт. Самые простые:
- **Netlify Drop**: https://app.netlify.com/drop — перетащи папку целиком.
- **GitHub Pages**: создай репозиторий, загрузи файлы, затем
  Settings → Pages → Branch: `main` → Save.
- **Vercel** или **Cloudflare Pages** — тоже бесплатно.

## 6. Разреши свой домен для входа
**Authentication → Settings → Authorized domains → Add domain** и добавь
адрес сайта, например `имя.netlify.app` или `имя.github.io`.
Без этого кнопка «Войти через Google» выдаст ошибку.

## Работа из России
- Хостинг: лучше **GitHub Pages** (обычно открывается стабильно).
  Netlify и Vercel в РФ часто блокируются, особенно с мобильного интернета.
- Тренажёр письма: скачай один раз файл
  https://cdn.jsdelivr.net/npm/hanzi-writer@3.5.0/dist/hanzi-writer.min.js
  и положи его в эту папку рядом с `index.html`. Тогда сайт не зависит
  от внешнего CDN. Без этого файла сайт попробует загрузить его с jsDelivr.
- Firebase (вход через Google и общая таблица) — сервис Google. Обычно
  работает, но при ограничениях мобильного интернета может не открываться.
  Карточки, тест и прописи работают и без него.

## Проверка локально
Открыть `index.html` двойным кликом нельзя (вход через Google не работает
с `file://`). Запусти в папке `python3 -m http.server 8000` и открой
http://localhost:8000 — `localhost` в Firebase разрешён по умолчанию.

## Как пользоваться вдвоём
Скинь другу ссылку на сайт. Каждый входит своим Google-аккаунтом,
во вкладке «Друзья» видна статистика всех, кто вошёл: сколько слов знает,
сколько иероглифов написал по памяти, лучший тест и дни подряд.
